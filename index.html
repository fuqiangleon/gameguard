GameGuard

输入密码解锁家长控制台

首次设置

连接配置 Gist，并设置一个打开控制台用的密码。

密码用于加密保存令牌，只存在这台设备上。忘记密码只能清除后重新设置。

使用说明

GameGuard 由两部分组成：孩子 Mac 上的管控程序，和你手机上的这个控制台。你在控制台改的设置会保存到 GitHub Gist，Mac 每 5 分钟读取一次。

它会做什么
  • 在不允许的时间：每分钟检查一次，自动关闭“管控的程序”里的游戏和 App，并屏蔽“屏蔽网站”里的网站。
  • 在允许的时间、临时放行期间或总开关关闭时：不做任何限制，网站自动恢复。
  • 关闭游戏时，孩子的屏幕右上角会弹出提示。
多久生效？

点击保存后，一般 5–10 分钟内在孩子的 Mac 上生效（GitHub 的缓存加上 Mac 每 5 分钟读取一次）。

想立即生效，在孩子的 Mac 上用管理员账户运行：

sudo rm -f /var/db/gameguard/config.cache && sudo /usr/local/bin/gameguard.sh
临时放行
  • +30 分钟 / +1 小时 / +2 小时：从现在开始放行。如果已经在放行中，会在原来的截止时间上继续延长。
  • 今天不限：放行到今晚 23:59。
  • 到指定时间：选一个时间；如果选的时间已经过了，会放行到明天的这个时间。
  • 结束放行：马上恢复按时间表管控。
  • 放行到期后自动恢复管控，不需要手动结束。
设置每周时间表
  • 在“时间表”里点某一天展开，点“+ 添加时间段”，选开始和结束时间。一天可以有多个时间段。
  • 没有时间段的那天就是全天不能玩。
  • 工作日设好一天后，可以点“复制到周一至周五”；周末同理。
  • 改完后点底部黑色条上的保存，不保存不会生效。
管控程序和屏蔽网站
  • 管控的程序：填进程名里的关键字（至少 4 个字符），比如 Discord。常用的可以点下面的快捷按钮添加。
  • 屏蔽网站：填主域名，比如 youtube.com，会同时屏蔽 www.youtube.com。其他子域名（如 m.youtube.com）需要单独添加，快捷按钮会一起加上。
  • 网站和游戏共用同一个时间表。
  • 网站被屏蔽后，浏览器需要完全退出再打开才会立即生效；已经打开的网页可能要刷新。
网站屏蔽不生效怎么办
  • 先看首页状态：如果是“临时放行中”或“现在可以玩”，网站本来就不会被屏蔽。
  • 在 Mac 上运行 sudo /usr/local/bin/gameguard.sh --show，确认能看到 site= 和“网站屏蔽：生效中”。
  • 运行 grep 0.0.0.0 /etc/hosts，确认网站已经写入。
  • Safari + iCloud 专用代理会绕过屏蔽：在孩子账户的 系统设置 → Apple 账户 → iCloud → 专用代理 里关闭。
  • 孩子如果使用 VPN 或代理，也可能绕过网站屏蔽。
密码和安全
  • 控制台的密码只存在你这台手机上，用来加密保存 GitHub 令牌。别人打开这个网页，没有密码什么都改不了。
  • 点右上角“锁定”或关闭标签页后，需要重新输入密码。
  • 忘记密码：在解锁页点“忘记密码”，清除后重新填写 Gist 地址和令牌（令牌找不到就在 GitHub 重新生成一个）。
  • 不要在孩子的设备上登录这个控制台。
  • 可以在 Safari 里点“分享 → 添加到主屏幕”，像 App 一样使用。
孩子的 Mac 需要注意
  • 孩子的账户必须是标准用户（系统设置 → 用户与群组），不能是管理员，否则可以自己卸载管控程序。
  • 管控对这台 Mac 上所有账户都有效（包括你自己的账户）。
  • 查看记录：sudo tail -20 /var/log/gameguard.log
  • 查看当前状态：sudo /usr/local/bin/gameguard.sh --show
更新 Mac 上的管控程序

只有管控程序本身增加了新功能时才需要更新；平时在控制台改设置不需要。用管理员账户在终端运行：

cd /tmp && curl -fsSL -o gg.zip https://github.com/fuqiangleon/gameguard/archive/refs/heads/main.zip
unzip -o -q gg.zip && cd gameguard-main/mac && sudo ./install.sh

卸载：在同一个目录运行 sudo ./install.sh uninstall。
